# 隐私

本页说明你使用 API 时服务会记录什么、不会记录什么。

## 会记录的内容

每个 API 请求，服务只保留请求元数据：

- 请求时间
- 密钥 ID（绝不是密钥本身）
- 模型和接口
- token 数量：输入、缓存输入和输出
- 耗时：首 token 时间和总耗时
- 结果：HTTP 状态码或错误码，以及请求 ID
- 网络地址（IP）以及据此得出的国家

## 不会记录的内容

API 请求的提示词和回答内容不会被保存。服务只保留数量和耗时，不保留内容。本站的试用场（Playground）只把对话保存在浏览器内存里，关闭标签页后即消失。

## 保留多久

请求元数据保留 {{RETENTION_DAYS}} 天。之后明细会被删除，只保留汇总数据。

## 聊天站点

Open WebUI 聊天站点中的对话不同：该产品会保存你的聊天记录以便你回看，服务所有者可能对其进行审计。请不要在其中输入你不希望所有者看到的内容。

## 谁能看到什么

- 持有密钥的人能看到模型名称和服务的整体负载，因为状态页和模型页会显示它们。
- 所有者可以按密钥查看上述元数据。
- 如果服务通过 Cloudflare 访问，Cloudflare 会终止 TLS 连接，并能看到经过它的流量。
- 在局域网内使用普通 HTTP 连接时，同一网络中的其他人可能读取流量。

## 你的密钥

服务只保存密钥的哈希和一小段预览。本站把你粘贴的密钥只放在浏览器当前标签页的会话存储里，并且只通过 Authorization 请求头发给本站。
