# TTS 平台全面优化设计说明

## 目标

把现有顺序表单升级为可长期维护的本地语音工作台，同时保持以下兼容边界：

- 统一入口仍为 `/gateway/tts/`，7000 与 worker 端口只监听回环地址。
- 保留 `POST /api/tts`、`GET /v1/models`、`POST /v1/audio/speech`。
- 原有 `voices/`、`outputs/` 和 `.env` 可原地复用，不移动模型与虚拟环境。
- 网页生命周期操作只允许本机直连，并通过固定模型白名单、忙碌保护与进程身份校验执行；不接受任意命令或路径。

### 字体与间距

- UI 字体：`Inter`, `Segoe UI`, `Microsoft YaHei`, 系统无衬线回退。
- 正文 14px/1.55，控件 13px/1.3，标题 18–24px。

- 所有可点击控件桌面最小 36px，移动端最小 44px。

### 图标

使用同一组 1.8px 圆角描边 SVG，全部以 `currentColor` 着色。导航、播放、下载、重试、取消、删除、录音和复制均使用语义明确的矢量图标，不使用 emoji 充当功能图标。

## 信息架构

### 桌面

- 左侧导航：`创建`、`音色库`、`任务`、`历史`、`模型`、`API`。
- 顶部：`语音工作台`、实时引擎可用数、刷新状态。
- 中央创建流：任意语种原文 → 自由目标语种翻译 → 合成文本 → 合成语种 → 参考音色 → 合成引擎 → 表现力参数 → 生成。
- 右侧运行轨：活跃任务、最近生成、失败重试和结果播放。
- 底部只显示真实连接信息：`统一入口 · 当前主机:端口 · 已连接`，不硬编码开发端口。

### 移动端

- 顶部保留标题、可用引擎数和刷新。
- 导航变为横向分区；创建页按单列排列。
- 原文和合成编辑器上下排列，音色横向滚动，引擎保持可读的两列布局。
- 任务与历史进入独立视图，不压缩在侧栏。
- 生成操作固定在安全区上方，不遮挡最后一项内容。

## 可见文案白名单

首屏允许出现：`语音工作台`、`创建`、`音色库`、`任务`、`历史`、`API`、`中文原文`、`英文文本`、`翻译`、`插入停顿`、`参考音色`、`添加音色`、`合成引擎`、`语速`、`语气`、`风格描述`、`生成语音`、`刷新状态`、实时状态与真实错误文案。

不增加营销口号、虚假 KPI、硬编码 GPU/显存数据或不存在的路径。

## 前端组件

- `AppShell`：导航、顶部状态、主内容与右侧运行轨。
- `CreateWorkspace`：双语编辑器、音色选择、引擎选择、表现力控制与生成操作。
- `VoiceLibrary`：录音/上传、预览、编辑和删除。
- `TaskQueue`：排队、运行、完成、失败、取消、重试。
- `OutputHistory`：搜索、引擎筛选、试听、下载和单项删除。
- `ModelManager`：安装状态、服务状态、显存加载状态与安全生命周期操作。
- `ApiGuide`：OpenAI 兼容地址、模型列表与复制按钮。
- 通用组件：按钮、图标、状态点、空状态、骨架屏、Toast、确认对话框、音频播放器。

## 后端能力

### 引擎注册表

- 并发探测本地 worker，缓存健康状态并记录延迟、最近检查时间与模型加载状态。
- API 引擎只返回是否配置，不返回 Key。
- 支持显式刷新，普通页面轮询不重复制造慢探测。

### 语种与模型生命周期

- 语言字段接受 `auto`、BCP-47 代码或任意语种名称，不设置平台级固定列表。
- 每个模型返回原生语种摘要；已知不支持时明确报错，不静默回退成英文。
- 新增 VoxCPM 2（30 种语言、音色克隆/声音设计）与 Qwen VoiceDesign（10 种语言、无需参考音频）。
- 安装、启动、预加载、释放显存和停止由固定目录与命令白名单驱动；运行中任务禁止卸载或停止。
- 统一入口拦截非本机的生命周期变更，LAN/API 客户端只读。

### 任务队列

- 提供批量创建、列表、详情、取消和重试接口。
- 全局并发限制与单引擎串行锁，防止同一模型并发导致显存峰值。
- 状态统一为 `queued`、`running`、`succeeded`、`failed`、`cancelled`。
- 旧 `/api/tts` 继续同步返回，供既有调用方使用。

### 音色与音频

- 上传大小、空文件、名称、参考文本、ffmpeg 超时和输出 WAV 统一校验。
- ffmpeg、波形读取和阻塞模型调用放入后台线程，不阻塞健康检查。
- 音色元数据原子写入；支持重命名与修改参考文本。

### 历史记录

- 使用数据目录中的 SQLite 建立输出索引；启动时自动收录既有 WAV。
- 支持分页、搜索、引擎过滤、试听、下载和单项删除。
- 保存引擎、音色、文本、参数、耗时、大小、时长与生成时间。

### API 与可靠性

- Pydantic 请求模型、统一错误码、请求 ID、安全响应头和滚动日志。
- `/health` 为轻量健康检查；`/api/system` 返回非敏感能力与存储状态。
- 翻译限制长度并返回实际 provider 与耗时；错误不暴露上游响应全文。
- OpenAI Audio 接口继续只支持 WAV，并返回引擎、耗时和请求 ID 头。

## 响应式与无障碍验收

- 桌面 1440×1024、笔记本 1280×800、移动 390×844。
- 页面无横向溢出，主操作不被遮挡，文本与播放器可完整使用。
- 全部表单具备 label，状态变化进入 `aria-live`，键盘可访问，焦点清晰。
- 支持 `prefers-reduced-motion`。
- 快捷键：`Ctrl+Enter` 生成，`Ctrl+Shift+T` 翻译，`Escape` 关闭对话框。
